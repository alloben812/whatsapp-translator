# WhatsApp Translator

Личный чат с переводом **русский ↔ сербский**, который работает с вашим обычным номером WhatsApp на существующем сервере Hetzner.

Вы выбираете собеседника и пишете по-русски. По кнопке **Перевести и отправить** он получает сербский перевод в обычном WhatsApp. Его ответ появляется рядом с русским переводом в вашем интерфейсе. Приложение самостоятельно не отвечает и не выбирает адресата.

## Текущее состояние

Реализованы браузерный интерфейс для компьютера и телефона, подключение WhatsApp через QR, сохранение сессии и контактов, приём новых текстовых сообщений, подписочный переводчик и статусы отправки, доставки и прочтения. На Hetzner установлены отдельная служба приложения и socket переводчика.

**WhatsApp ещё не привязан.** На сервере проверен release `f8a47fa`: получение QR подтверждено, настоящий Claude Sonnet перевёл тестовые фразы в обе стороны примерно за 12 секунд на запрос. Реальная переписка с WhatsApp ещё не проверена.

Последняя зафиксированная offline-проверка: **44 теста Node.js и 16 тестов Python**, а также демонстрация без сети. Интерфейс проверен на локальных примерах. Эти результаты не означают, что живой обмен сообщениями уже проверен.

## Как открыть приложение

На текущем Mac запустите `scripts/open-translator.command` из этой папки, затем откройте [переводчик](http://127.0.0.1:8787). Скрипт создаёт приватный SSH-канал к серверу. Технический пульт другого проекта для переписки не нужен.

Для привязки WhatsApp:

1. Нажмите **Подключить WhatsApp**.
2. На телефоне откройте WhatsApp → **Настройки → Связанные устройства → Привязка устройства** и отсканируйте QR со страницы.
3. Добавьте имя и точный номер собеседника с кодом страны, затем выберите этот чат.
4. Напишите по-русски и нажмите **Перевести и отправить**. `Enter` отправляет, `Shift + Enter` переносит строку.
5. Читайте ответы на русском рядом с сербским оригиналом.

Страница сейчас доступна с Mac через SSH; **публичного адреса для телефона пока нет**. После привязки сервер сможет принимать и переводить новые сообщения добавленных контактов при выключенном компьютере. Старую историю WhatsApp приложение не импортирует.

Если перевод не получился или WhatsApp отключился до отправки, исходный текст можно вернуть в поле. Если результат отправки неизвестен, приложение проверяет прежний запрос и не отправляет его повторно. Перед ручным повтором нужно проверить обычный чат WhatsApp.

## Модель и лимиты

По явному решению владельца используются **существующие подписки и их обычные лимиты**, без дополнительного ограничения другого проекта «20% недельной квоты в день». Допуск и настройки остальных задач сохраняются.

По умолчанию — **Claude Sonnet**. При явном выборе допустим **GPT-5.5**; автоматического перехода на другую модель или платный API нет. Сербская латиница пока предложена по умолчанию, но не подтверждена как предпочтение владельца.

## Проверка кода без WhatsApp

Нужны Node.js **22.17+**, Python 3 и доступ GitHub CLI к приватному репозиторию.

```sh
gh repo clone alloben812/whatsapp-translator
cd whatsapp-translator
npm ci --ignore-scripts
npm run doctor
npm test
npm run demo
```

`doctor` проверяет Node.js и встроенный SQLite. Тесты проверяют ядро, HTTP, адаптеры и broker на подменённых зависимостях. `demo` использует фиксированные переводы и временную БД. Эти команды не подключают WhatsApp и не вызывают модели. Секреты и развёртывание в CI не используются.

Для реальной службы следуйте [инструкции развёртывания](docs/live-deployment.md). Установка зависимостей сама по себе не привязывает WhatsApp и не создаёт подписочный доступ.

## Ограничения и данные

Текущая версия поддерживает личные текстовые чаты добавленных собеседников: без групп, звонков, голосового ввода, медиа и автономных ответов. Выбор других языков и диктовка с проверкой текста запрошены как следующий этап, но ещё не входят в эту поставку. Исходное сообщение ограничено 4000 символами. Интерфейс показывает последние 500 записей; старые остаются в БД, просмотра старой истории пока нет. Один экземпляр службы работает с одной SQLite-БД.

Baileys — неофициальный способ подключения личного WhatsApp: возможны сбои и ограничения аккаунта. Текст для перевода передаётся выбранному провайдеру. База и сессия WhatsApp хранятся в приватном каталоге сервера; рабочие данные переводов также сохраняются у подписочного исполнителя. Автоматическая очистка и восстановление зашифрованной резервной копии пока не реализованы.

Код хранится в GitHub. SSH-ключи, модельные входы, QR, сообщения и сессии в Git не попадают; веб-приложение не получает содержимое подписочных учётных данных.
