# WhatsApp Translator

Личный чат с переводом **русский ↔ язык собеседника**, который работает с вашим обычным номером WhatsApp на существующем сервере Hetzner.

Вы выбираете собеседника и пишете по-русски. По кнопке **Перевести и отправить** он получает перевод на выбранном языке в обычном WhatsApp. Его ответ появляется рядом с русским переводом в вашем интерфейсе. Приложение самостоятельно не отвечает и не выбирает адресата.

## Текущее состояние

Реализованы автоматический список личных чатов WhatsApp с именами и доступными последними сообщениями, выбор из 16 вариантов языка для каждого контакта, голосовой ввод на русском, браузерный интерфейс для компьютера и телефона, подключение WhatsApp через QR, сохранение сессии и контактов, приём новых текстовых сообщений, подписочный переводчик и статусы отправки, доставки и прочтения. На Hetzner установлены отдельная служба приложения и socket переводчика.

**Владелец привязал WhatsApp и подтвердил работу приложения.** В рабочей БД есть входящие переводы и прочитанные исходящие. Настоящий Claude Sonnet также проверен на тестовых фразах русский ↔ сербский и русский → английский (примерно 12–13 секунд на запрос), локальный Whisper small/int8 — на WAV и WebM (примерно 11 секунд).

Личный список учитывает закрепления, последнее сообщение и архив WhatsApp. Контакты без полученных данных о переписке показаны отдельно. При самом первом подключении старая версия пропустила начальную историю: имена восстановлены, но порядок большинства старых чатов пока неизвестен. Обычное обновление списка эту историю не повторяет; новая привязка для её получения требует отдельного действия владельца. Действующую сессию автоматически не сбрасывать.

Сборка и поведенческие тесты проходят без сети и секретов. Последние результаты проверок приведены в checkpoint. [Точные результаты живой проверки](docs/live-checkpoint-2026-09-18.md).


## Как открыть приложение

На текущем Mac запустите `scripts/open-translator.command` из этой папки, затем откройте [переводчик](http://127.0.0.1:8787). Скрипт создаёт приватный SSH-канал к серверу. Затем войдите с отдельным паролем переводчика; кнопка **Выйти** блокирует страницу, сохраняя подключение WhatsApp. Технический пульт другого проекта для переписки не нужен.

Для привязки WhatsApp:

1. Нажмите **Подключить WhatsApp**.
2. На телефоне откройте WhatsApp → **Настройки → Связанные устройства → Привязка устройства** и отсканируйте QR со страницы.
3. Дождитесь списка личных чатов, выберите собеседника и задайте его язык в заголовке. При необходимости нажмите **Обновить чаты**. Ручное добавление номера оставлено как запасной способ.
4. Напишите по-русски или нажмите **Надиктовать**, завершите запись и проверьте текст. Затем нажмите **Перевести и отправить**. `Enter` отправляет, `Shift + Enter` переносит строку.
5. Читайте ответы на русском рядом с оригиналом.

Страница сейчас доступна с Mac через SSH; **публичного адреса для телефона пока нет**. Сервер принимает и переводит новые сообщения выбранных контактов при выключенном компьютере. Загрузка списка сама по себе не включает перевод всех контактов: перевод включается при открытии конкретного чата. Старую переписку приложение не переводит и не показывает как полный архив; доступные последние сообщения используются только для списка чатов.

Если перевод не получился или WhatsApp отключился до отправки, исходный текст можно вернуть в поле. Если результат отправки неизвестен, приложение проверяет прежний запрос и не отправляет его повторно. Перед ручным повтором нужно проверить обычный чат WhatsApp.

## Модель и лимиты

По явному решению владельца используются **существующие подписки и их обычные лимиты**, без дополнительного ограничения другого проекта «20% недельной квоты в день». Допуск и настройки остальных задач сохраняются.

По умолчанию — **Claude Sonnet**. При явном выборе допустим **GPT-5.5**; автоматического перехода на другую модель или платный API нет. Начальный язык нового контакта — сербский, латиница. Его можно поменять при добавлении или в заголовке чата; история сохраняет прежние языки.

## Проверка кода без WhatsApp

Нужны Node.js **22.17+**, Python 3 и доступ GitHub CLI к приватному репозиторию.

```sh
gh repo clone alloben812/whatsapp-translator
cd whatsapp-translator
git switch codex/live-translator
npm ci --ignore-scripts
npm run doctor
npm test
npm run demo
```

`doctor` проверяет Node.js и встроенный SQLite. Тесты проверяют ядро, HTTP, адаптеры и broker на подменённых зависимостях. `demo` использует фиксированные переводы и временную БД. Эти команды не подключают WhatsApp и не вызывают модели. Секреты и развёртывание в CI не используются.

Для реальной службы следуйте [инструкции развёртывания](docs/live-deployment.md). Установка зависимостей сама по себе не привязывает WhatsApp и не создаёт подписочный доступ.

## Ограничения и данные

Текущая версия поддерживает личные текстовые чаты добавленных собеседников и диктовку русского текста до 60 секунд. Запись обрабатывается локально на сервере, после распознавания удаляется и автоматически не отправляется. Голосовые сообщения собеседника, группы, звонки, медиа и автономные ответы не поддерживаются. Исходное сообщение ограничено 4000 символами. Интерфейс показывает последние 500 записей; старые остаются в БД, просмотра старой истории пока нет. Один экземпляр службы работает с одной SQLite-БД.

Baileys — неофициальный способ подключения личного WhatsApp: возможны сбои и ограничения аккаунта. Текст для перевода передаётся выбранному провайдеру. База и сессия WhatsApp хранятся в приватном каталоге сервера; рабочие данные переводов также сохраняются у подписочного исполнителя. Автоматическая очистка и восстановление зашифрованной резервной копии пока не реализованы.

Код хранится в GitHub. SSH-ключи, модельные входы, QR, сообщения и сессии в Git не попадают; веб-приложение не получает содержимое подписочных учётных данных.
