## Обновление: аудит и обязательный вход

Текущий серверный release: `64b8ddfe293f2069a6bec7f331be6dab951d19a2`. Владелец разрешил добавить пароль поверх SSH. Установлен случайный пароль; сервер использует scrypt-хеш через systemd credential. Первичная открытая копия перенесена по SSH в локальный файл владельца с правами 0600 и удалена с сервера; хеш и WhatsApp-сессия сохранены.

Проверено на работающей службе: без cookie `/api/state`, `/api/send`, `/api/transcribe`, `/api/chats/open` и `/api/retry-translation` возвращают 401; неверный пароль отклоняется; правильный открывает state с `auth.required=true`, `connected`, 96 собеседниками и готовым переводчиком. После `/api/logout` прежний cookie получает 401. Реальные отправки, перевод и микрофон не запускались. Браузер владельца обновлён и показывает экран входа.

Проверены права доступа между пользователями: веб-приложение не читает credentials Claude/Codex; пользователи моделей и публичного gateway не читают WhatsApp-сессию и не подключаются к sockets переводчика. Mac слушает только `127.0.0.1:8787`; порт 8787 сервера извне недоступен. Чужие Host/Origin и cross-site запросы отвергаются. Публичный HTTPS другого проекта требует авторизацию и не проксирует WhatsApp. Чужие службы сохранили свои PID.

66 Node-тестов и 26 Python-тестов прошли, включая provision/hash, авторизацию, отзыв и срок сессии, burst limits и общий предел директории. Для полной локальной Python-проверки использован runtime с OpenSSL scrypt; системный Apple Python пропускает два криптографических теста, Linux CI выполняет их. В браузере на тестовой странице проверены вход, выход и удаление отрисованных контактов/сообщений. Подробная модель защиты и оставшиеся ограничения — [security.md](security.md).

## Обновление: подключённый аккаунт и список собеседников

Release синхронизации: `4efb42dccb82c16e4114468ac161e23a0165923b`. Владелец привязал WhatsApp самостоятельно. После обновления приложение восстановило соединение с сохранённой сессией и получило **95 личных собеседников с именами** через app-state sync. Повторная привязка, сброс credentials или восстановление курсоров не потребовались.

Проверено на действующем сервере: `connected`, `chatSync=ready`, 95 записей директории, 0 активированных для перевода контактов и 0 сообщений приложения. При этой синхронизации последние тексты не пришли; список показывает имена и номера. Открытая страница обновлена и действительно показывает 95 строк, включая узкий интерфейс со списком вместо прежнего пустого экрана разговора.

64 Node-теста и 21 Python-тест прошли; `npm run demo` тоже прошёл. Проверены сохранение директории после открытия БД заново, ручное открытие чата, mapped LID, порядок preview, CSRF, отсутствие модельных вызовов и отправок при импорте. В браузере на фикстурах выбран ранее неактивный чат: появился его язык и поле ввода, отправки не было.

Список синхронизируется автоматически и по **Обновить чаты**. Открытие конкретного чата включает для него перевод новых входящих; импорт всего списка не переводит историю. Полная старая переписка пока не показывается. Во время этой проверки реальные сообщения не отправлялись, модели не вызывались; первый разрешённый обмен остаётся отдельной проверкой по конкретной команде владельца.

## Первоначальная проверка компонентов

- 59 Node-тестов и 21 Python-тест прошли локально; GitHub Actions на Linux для этого commit завершился успешно: <https://github.com/alloben812/whatsapp-translator/actions/runs/35369220519>.
- Реальные подписочные переводы Claude Sonnet: русский → сербский за 12.0 с; сербский → русский за 12.1 с; новый явный русский → английский за 12.68 с. Использованы только синтетические фразы. Время и числа сохранены; это отдельные замеры, не гарантия задержки.
- Локальный Whisper small/int8 распознал 4.09-секундную синтетическую русскую запись: WAV за 10.93 с, WebM/Opus за 10.65 с. В обоих случаях получено: «Здравствуйте, я хотел бы записаться на завтра в 3 часа дня.»
- Пиковая память службы во время распознавания: 751448064 байта, около 717 MiB. После завершения subprocess память освобождается. Ограничение службы — 1900 МБ и 175% CPU.
- В браузере проверены выбор языка контакта, сохранение прежнего языка в истории и доступность кнопки диктовки. Сам микрофон владельца не включали; отмена, отказ разрешения и гонки записи проверены на подменённых браузерных зависимостях.
- Получение QR от WhatsApp и показ на странице проверены. QR, модельные credentials и ключи в Git не сохранялись.

## Принятые решения

Для перевода действуют обычные лимиты существующих подписок. Отменённое владельцем дополнительное правило другого проекта «20% недельной квоты в день» не применяется: конфигурация переводчика принимает только `subscription_limits`. По умолчанию Claude Sonnet; GPT-5.5 разрешён как отдельный выбор оператора. Платный API и автоматическая смена модели отсутствуют.

Для каждого контакта сохраняется один из 16 вариантов языка. Русский остаётся языком владельца. Смена настройки не меняет историю или повтор обработки уже сохранённого сообщения. Диктовка до 60 секунд обрабатывается локально, временное аудио удаляется, результат дополняет черновик и требует явной отправки.
