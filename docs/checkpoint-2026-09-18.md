## Почему модельный цикл пока не готов

GET `/state` через `/run/multimodeagents-control/control.sock` вернул:

- `execution.enabled=false`, причина `project_package_required`.
- Для Codex и Claude: `ledger.decision.allowed=false`, причина `backend_freshness_unknown`; дневной `canExecute=false`.
- У обоих отсутствует подтверждённая исходная точка дня (`missing_day_baseline`). У Codex также есть разрывы `window_reset` / `invalid_reset_transition`.
- Последнее принятое наблюдение Claude — **15 сентября, 17:20:25 UTC**, хотя наблюдающая служба завершалась с кодом 0 уже 18 сентября. Успешное завершение сборщика не доказывает свежесть квоты.
- При проверке последнее принятое наблюдение Codex — **18 сентября, 15:26:55 UTC**; его свежесть на стороне провайдера и полный дневной учёт не подтверждены.

`control.paused=false` не является разрешением обходить дневной допуск. Проценты старого наблюдения не следует считать текущим остатком. Настройки квот, baseline, permits и резервов в этой подготовке не менялись. Проверочные модельные запросы не выполнялись.
